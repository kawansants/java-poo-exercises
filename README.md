# Java Object-Oriented Programming Exercises

A collection of Java exercises focused on Object-Oriented Programming (OOP), developed as part of my Java learning journey.

## Exercises

### 01 - Rectangle
Calculate the area, perimeter, and diagonal of a rectangle.

Concepts:
- Classes and objects
- Attributes and methods
- Mathematical operations
- Return values

### 02 - Student
Calculate a student's final grade, determine approval status, and display missing points when applicable.

Concepts:
- Classes and objects
- Boolean methods
- Conditional statements
- Method reuse

### 03 - Employee
Calculate an employee's net salary and apply a percentage-based salary increase.

Concepts:
- Classes and objects
- Methods with parameters
- Void methods
- Object state modification
